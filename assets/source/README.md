# source

`higgsfield-sphere.png`: one still generated with Higgsfield (`z_image` model, 2026-10-29), used under
Higgsfield's content terms. Prompt: a glowing translucent glass sphere floating in the centre of a pure white
background, soft studio light, no text.

The brief asked for a 4 s video clip, but Higgsfield video generation needs a paid plan, so this is a single
still. `tools/scanline/clip.py` traces only the sphere from it; the vector, photons and key in
`assets/hero-alt` are the same BB84 simulation as the main hero, drawn on top.
